## Description
Add the two composable world-trigger components. `Interactable` (Area3D, collision layer 3 / mask 2
to detect the player) holds `@export var dialogue: DialogueData` and `@export var advance_stage_on_complete:
bool`. On the `interact` press — only while the player is in range, `SceneRouter` is not transitioning,
and `DialogueService` is not open — it awaits `DialogueService.play(dialogue)`; when that returns and
`advance_stage_on_complete` is set, it calls `GameFlow.request_advance_stage()`. Re-triggering a
non-advancing NPC simply replays the same `DialogueData` (no softlock). `StageExit` (Area3D, layer 3 /
mask 2) calls `GameFlow.request_advance_stage()` when the player body enters, gated by the same
transition guard. Both components use explicit layer/mask (never defaults) and `call_deferred` for any
tree mutation from body signals. Consume the opening interact press so it cannot also be read as an
advance press. Follow `design.md`.
