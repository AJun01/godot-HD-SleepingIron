## Description
Add the minimal boot scene and make it the configured main scene, closing the loop. On `_ready`,
the boot scene calls `GameFlow.start_flow()`, which routes to the menu through SceneRouter — the
first real transition, proving the single progression entry. This is the point where the full
boot → menu → (New Game) → chapter → (ui_cancel) → menu loop becomes observable: every scene change
goes through GameFlow + SceneRouter, the SceneRouter in-progress guard makes duplicate transition
requests no-ops, and GameFlow's state guard blocks input issued before a transition completes.
Follow design.md for the global pattern.
