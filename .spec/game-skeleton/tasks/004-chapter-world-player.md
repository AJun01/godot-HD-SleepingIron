## Description
Build the HD-2D chapter scene: a lit 3D world (DirectionalLight3D + WorldEnvironment owned by the
world scene) with a ground plane using the placeholder ground texture, a billboarded placeholder
player (CharacterBody3D + Sprite3D, billboard enabled) that moves in 8 directions via
`Input.get_vector` on the move actions, a billboarded placeholder environment prop, and a Camera3D
follow component. Movement tunables come from PlayerConfig (.tres), not hardcoded values. Explicit
collision layers/masks: player on layer 2 (mask = world layer), ground on layer 1. The chapter
controller only forwards `ui_cancel` to `GameFlow.request_quit_to_menu()` — progression stays owned
by GameFlow. Follow design.md for the global pattern.

## Acceptance
- [ ] `godot --headless --editor --path . --quit-after 10` is clean.

- [ ] Player moves in 8 directions via InputMap move actions; movement tunables read from PlayerConfig (.tres).

- [ ] Every physics body has explicit collision layer + mask (player layer 2 / world layer 1); no defaults.
- [ ] ui_cancel forwards to GameFlow.request_quit_to_menu(); the chapter never self-advances progression.
