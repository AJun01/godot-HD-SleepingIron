## Description
Create a side-view follow camera component (extends Camera3D), mirroring the existing follow component's
`@export` target + NodePath fallback + exponential-smoothing pattern but with side-view semantics: no
`look_at` (keep identity rotation so it looks horizontally forward), X lerps toward the target's X, Y stays
fixed at `vertical_offset` (default 1.2 m), Z stays fixed at `z_distance` (default 10.0 m behind the play
plane). It is a new component; the existing top-down follow and the chapter cameras are untouched. It will be
wired into the arena scene in task 004. Follow design.md for the global pattern.
