## Description
Extend `objective_hud.gd` with `show_test_health_bar()` / `hide_test_health_bar()` that lazily build a ProgressBar in the HUD's existing CanvasLayer (same pattern as its objective label) and toggle its visibility — a system smoke test, not real health. Add `ui_hud_trigger.gd` (Area3D, interaction layer 3, mask 2) with an `@export` mode (health vs dialogue): the health trigger shows the bar on `body_entered` and hides it on `body_exited` (via ObjectiveHud); the dialogue trigger calls `DialogueService.play()` with the minimal `hub_test` DialogueData on `body_entered` (guarded by `is_open()`), so the box shows and is dismissed through the existing advance flow. Place both triggers in the UI/HUD zone. Register the artifacts. Follow design.md.
