## Description
Introduce the minimal learning-first save/load service: a new `SaveService` autoload that persists the player's position (Vector3) and facing (int) to `user://arena_save.json` and reads them back (returning an empty dict on failure) — statically typed, no full save system. Register it in project.godot's `[autoload]`. Add a composable `save_load_trigger.gd` Area3D on interaction layer 3 / mask 2 with `@export` `save_mode` (true = save, false = restore) and a `player_path`; on `body_entered` it either saves the player's position + facing or restores them, applying the restored position/facing via `call_deferred` (tree/physics mutation from a signal callback). Place two trigger pads in the save/load zone: one save, one restore. Register the artifacts. Follow design.md.

## Acceptance
- [ ] `SaveService` autoload is registered and statically typed; save writes JSON to `user://arena_save.json`; load returns position + facing, or empty on failure.
- [ ] The save trigger stores the player's position + facing; the restore trigger returns the player to the saved position + facing (via `call_deferred`).
- [ ] Both trigger pads use explicit interaction layer 3 / mask 2; no defaults.
- [ ] `gdlint .` reports 0 problems.
