## Description
Extend `player_animator.gd` with a minimal preview mode: `play_preview(animation: StringName)` forces a specific animation (skipping the physics-derived mapping) while `stop_preview()` resumes auto-mapping; facing flip still applies. Add `animation_preview_zone.gd` (Node3D) that owns the player/animator/status-label refs, holds the 12-animation const list, and connects two proximity pads: "next animation" (cycles through all 12, wrapping) and "flip facing" (`player.facing = -player.facing`). Show the current animation name on a status Label3D for observability. Use `call_deferred` for sprite/tree mutations from the `body_entered` physics signal. Wire the pads in the animation preview zone (interaction layer 3, mask 2). Register the artifacts. Follow design.md.

## Acceptance
- [ ] The control cycles through all 12 animations (idle, run, jump, fall, land, attack_1/2/3, attack_air, hit, dodge, death) on the player character.
- [ ] The flip-facing toggle reverses the player's facing (the sprite flip updates).
- [ ] A status Label3D shows the current animation name.
- [ ] Leaving the zone / `stop_preview()` resumes normal physics-driven animation.
- [ ] `gdlint .` reports 0 problems.
- [ ] `godot --headless --editor --path . --quit-after 10` is clean; `godot --headless --path . --quit-after 5 scenes/act/arena.tscn` is clean.
- [ ] `docs/sdd/artifacts/arena-dev-hub.yml` registers the preview controller + animator extension.
